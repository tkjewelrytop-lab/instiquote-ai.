# InstiQuote AI 校园采购工作台

中文、手机优先的可操作 Web 原型：老师发布需求、供应商独立报价、管理员跟进派单，老师比较方案并选择供应商。

## 本地运行

安装 Node.js 后，在项目目录运行：

```sh
node server.cjs
```

浏览器打开 <http://127.0.0.1:4173/>。项目无第三方运行依赖，也可直接打开 `docs/index.html`；本地文件模式的数据持久化行为依浏览器而异。

## 操作体验

1. 顶部切换「老师」，新建报价需求，完成三步表格。演示验证码为 `123456`，不会发送真实短信。
2. 切换「供应商」，选一间演示公司，对同一需求确认接单并填写报价。
3. 切换「管理员」，查看派单、审核供应商、补派，或结束收集并交付现有报价。
4. 回到「老师」，收到五份报价或管理端结束收集后，可比较匿名方案、确认选择并查看获选供应商的模拟联络资料。
5. 侧栏「重置演示数据」会清除当前浏览器中的修改，并恢复示例需求。

## 发布到 GitHub Pages

本项目使用静态文件，无需构建或安装前端依赖。

1. 将项目文件提交到 GitHub 仓库的 `main` 分支。
2. 打开仓库 **Settings → Pages**。
3. 在 **Build and deployment** 中，将 **Source** 设为 **Deploy from a branch**。
4. 将分支设为 **main**，目录设为 **/docs**，点击 **Save**。
5. 等待 Pages 部署完成，使用该页面返回的网站链接访问原型。

`docs/.nojekyll` 用于直接发布静态资源。所有页面资产都使用相对路径，适合仓库子路径部署。

## 验证

运行八个业务规则测试场景：

```sh
node model.test.cjs
```

测试覆盖损坏存储恢复、表单验证、派单资格与同公司去重、五个接单名额、创建到选择的完整流程、截止限制及部分报价、供应商审核与停权、平台问答。

## 原型范围

- 需求、报价及操作记录仅保存在当前浏览器的 `localStorage`，不在不同设备、浏览器或网址之间共享。
- 三种角色之间的切换为演示导航，不是真实登录或权限隔离。
- 短信、WhatsApp、电邮及 AI 尚未连接真实服务。
- 附件只记录文件名、大小和类型，不上传或储存文件内容。
- 公司、学校、报价和联络资料为模拟数据；请使用演示资料体验。
- 接单确认与实际提交报价分别计数。截止或结案后不能继续接单或提交报价。
- 补派只增加尚未邀请且符合条件的供应商；自动释放失约名额和定时补派尚未实现。
